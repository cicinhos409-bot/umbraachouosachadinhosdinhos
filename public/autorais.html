Editar Origem 📥

Dica: Se os vídeos caem no chat "Geral", digite 1. Se for um canal sem tópicos, digite 0 para ler tudo.

A confirmação do grupo (nome e acesso) é feita pelo bot no Telegram. Aqui o protótipo só lê o texto digitado: a confirmação do nome fica a confirmar com o servidor ligado.

Editar Destino 📤

No bot, se o destino não for encontrado, aparece o aviso "verifique se ele é administrador do canal" e o ID é salvo mesmo assim. Aqui a checagem com o Telegram não existe (a confirmar com o servidor ligado).
